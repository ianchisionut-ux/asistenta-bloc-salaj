# Asistență Bloc Sălaj

Landing page responsive pentru serviciile de administrare imobile din județul Sălaj.

## Dezvoltare locală

```bash
npm run dev
```

Site-ul va fi disponibil la `http://127.0.0.1:4173`.

## Verificare

```bash
npm run check
```

Proiectul este static și poate fi publicat direct pe Vercel, fără pas de build.
